# FreshBite — Online Food Ordering

**Internship task:** WD-EC-001 · FreshBite – Online Food Ordering  
**Project type:** Frontend-only e-commerce website  
**Technologies:** HTML5, CSS3, vanilla JavaScript, browser LocalStorage

## Overview
FreshBite is a responsive food-ordering website demo where visitors can browse food categories, search dishes, filter by dietary preference, add products to a basket, adjust quantities, apply a coupon, and complete a simulated checkout. It also includes a demo account profile, wishlist, recent order history, restaurant cards, About and Contact sections.

## Features
- Responsive layout for desktop, tablet, and mobile
- Home hero, food categories, offer banner, restaurant listings, food menu, About and Contact sections
- Search by dish name/description and dietary filters (vegetarian, non-vegetarian, vegan)
- Add-to-cart, quantity adjustment, subtotal, delivery fee, discount, and total calculations
- `FIRSTBITE` coupon for a simulated 10% discount
- Checkout form with delivery time and simulated payment method selection
- Simulated order confirmation and order history
- Wishlist and demo user profile
- LocalStorage persistence for cart, profile, wishlist, and order history
- Accessible labels, responsive navigation, and reduced-motion support

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser. No build step or package installation is required.
3. For a local development server, open the folder in VS Code and use Live Server, or run `python3 -m http.server 8000` in this folder and visit `http://localhost:8000`.

## Project files
- `index.html` — semantic page structure and sections
- `style.css` — visual design, responsive layout, and animations
- `script.js` — menu data, search/filter, cart, coupon, checkout, wishlist, profile, and LocalStorage logic
- `PROJECT_REPORT.md` — concise project report
- `SUBMISSION_CHECKLIST.md` — tasks to complete before submission

## Important limitations
This is a learning/demo frontend, not a production ordering service. Authentication is simulated; there is no backend, database, live restaurant integration, real order dispatch, map service, or payment gateway. Contact form submissions stay in the browser. Do not enter sensitive personal or payment information.
